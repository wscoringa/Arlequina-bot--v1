## 💜 Sobre o Bot

O **Arlequina Bot V1** é um bot para WhatsApp desenvolvido em **Node.js** utilizando a biblioteca **Baileys**.

Ele foi criado para oferecer uma experiência moderna, rápida e divertida, contando com diversos recursos para grupos e uso pessoal.

### ✨ Recursos

- 👑 Comandos para administradores
- 🎮 Diversão e RPG
- 🤖 Sistema moderno
- 🖼️ Figurinhas
- ⚡ Rápido e leve
- 📱 Compatível com Termux
- 🔒 Base em Baileys

---

# 📥 Instalação (Termux)

### Clone ou extraia o projeto e execute:

```bash
cd /storage/emulated/0/Download/Arlequina-bot-v1

pkg install python build-essential

npm config set bin-links false

npm install --no-bin-links

npm install

npm start
```

---

# 📦 Requisitos

- Node.js
- NPM
- Python
- Build Essential
- Termux atualizado

---

# 🚀 Como iniciar

Após instalar todas as dependências:

```bash
npm start
```

Depois basta conectar utilizando o **QR Code** ou **Pairing Code**.
